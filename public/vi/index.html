Giới thiệu

Tôi là một lập trình viên đam mê phát triển ứng dụng web, với nền tảng vững chắc về lập trình và luôn hướng tới việc kết hợp công nghệ với sự sáng tạo. Hiện tôi đang theo học chương trình Kỹ sư Công nghệ Thông tin tại Đại học Công nghệ TP.HCM.

Tôi tập trung xây dựng các ứng dụng web sử dụng Java Spring Boot, JavaScript và chia sẻ kiến thức thông qua blog cá nhân.

JavaScript Modules …

Modules giúp tách code thành các file reusable.

Ví dụ

math.js

export function add(a, b) { return a + b; }
export function sub(a, b) { return a - b; }

app.js

import { add } from './math.js';
console.log(add(2,3)); // 5

N.B. Modules giúp tránh global scope pollution và tăng maintainability.

Functional Programming in …

Java 8 trở đi hỗ trợ lập trình functional với lambda và streams.

Ví dụ

List<Integer> numbers = Arrays.asList(1, 2, 3, 4);
numbers.stream()
       .map(n -> n * n)
       .forEach(System.out::println);

  • map, filter, reduce là những function quan trọng.
